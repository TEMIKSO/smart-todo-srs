## Диаграммы поведения системы  

### Use Case Диаграмма  
Описание основных сценариев использования приложения "Интервальные повторения"  

### Акторы:  
- **Пользователь** - основной пользователь системы, изучающий материал по карточкам  
- **Система** - автоматическое планирование повторений и напоминаний  

### Основные Use Cases:  

---

- **Управление карточками**:  
  - Создание новой карточки (вопрос + ответ)  
  - Редактирование существующей карточки  
  - Удаление карточки  
  - Группировка карточек по колодам/тегам  

- **Процесс обучения**:  
  - Проведение сессии повторений  
  - Оценка знания карточки (0-5 баллов)  
  - Просмотр статистики прогресса  
  - Экспорт/импорт колод  

- **Организация материала**:  
  - Создание и управление колодами  
  - Фильтрация карточек по статусу/тегам  
  - Настройка алгоритма повторений (SM-2, FSRS)  

- **Аналитика и отчеты**:  
  - Просмотр ежедневной статистики  
  - Анализ слабых мест  
  - Генерация рекомендаций  

## Диаграммы последовательности  

### 1. Добавление карточки  
Показывает процесс создания новой карточки с автоматическим расчетом первого интервала повторения  

### 2. Пометка изученного
Демонстрирует процесс оценки знания карточки и пересчета следующего интервала по алгоритму SM-2  

### 3. Фильтрация карточек  
Отображает механизм фильтрации карточек по колодам, тегам и статусу готовности к повторению  

### 4. Ежедневный workflow
Комплексный сценарий типичной учебной сессии пользователя

## Используемые инструменты  
- **PlantUML** - для кодового представления диаграмм 
- **draw.io** - для визуального редактирования
